Provides high-performance, zero-boxing primitive collections including resizable tables ({@code FastTable}) and open-addressing hash sets ({@code FastSet}) for Java primitive types, avoiding object creation and auto-boxing overhead.

Overview:

All primitive collections in this package extend the abstract base class {@link javolution.util.primitive.FastPrimitiveCollection FastPrimitiveCollection} and implement {@link javolution.lang.Reusable Reusable} for zero-GC object recycling:

Migration from the pre-6.0 API:

Version 6.0 removes the former {@code FastArrayList} classes in favor of {@code FastTable}, and replaces {@code FastPrimitiveList} with {@code FastPrimitiveCollection}. This is an intentional source and binary compatibility break: applications must update imports and recompile. No deprecated aliases, adapters, or duplicate compatibility classes are provided.

1. Resizable Segmented Tables:

  • {@link javolution.util.primitive.FastBooleanTable FastBooleanTable} for boolean
  • {@link javolution.util.primitive.FastByteTable FastByteTable} for byte
  • {@link javolution.util.primitive.FastCharTable FastCharTable} for char
  • {@link javolution.util.primitive.FastShortTable FastShortTable} for short
  • {@link javolution.util.primitive.FastIntTable FastIntTable} for int
  • {@link javolution.util.primitive.FastLongTable FastLongTable} for long
  • {@link javolution.util.primitive.FastFloatTable FastFloatTable} for float
  • {@link javolution.util.primitive.FastDoubleTable FastDoubleTable} for double

2. Open-Addressing Hash Sets:

  • {@link javolution.util.primitive.FastBooleanSet FastBooleanSet} for boolean
  • {@link javolution.util.primitive.FastByteSet FastByteSet} for byte
  • {@link javolution.util.primitive.FastCharSet FastCharSet} for char
  • {@link javolution.util.primitive.FastShortSet FastShortSet} for short
  • {@link javolution.util.primitive.FastIntSet FastIntSet} for int
  • {@link javolution.util.primitive.FastLongSet FastLongSet} for long
  • {@link javolution.util.primitive.FastFloatSet FastFloatSet} for float
  • {@link javolution.util.primitive.FastDoubleSet FastDoubleSet} for double

Architecture & Real-Time Predictability:

Unlike standard collections that allocate huge contiguous arrays or individual entry objects, {@code FastTable} allocates memory in small, fixed blocks of 1024 elements (Zero-GC fragmentation), and {@code FastSet} utilizes high-dispersion open-addressing hash tables with linear probing directly over flat primitive arrays, reducing memory consumption by 80-90%.

Primitive Iterators and Views:

Iteration without boxing is supported via {@link javolution.util.primitive.FastPrimitiveIterator FastPrimitiveIterator} and specialized primitive iterator interfaces (such as {@link javolution.util.primitive.FastIntIterator FastIntIterator}). In addition, each primitive collection supports thread-safe views (via shared()) and read-only views (via unmodifiable()).
